## こども

micro:bit をふると、グー・チョキ・パーのどれかが出る「じゃんけんマシン」を作ろう。
どれが出るかは、micro:bit にも分からない。コンピューターに「でたらめな数」をえらんでもらうんだ。

### できあがりのイメージ

下の「ゆさぶる」を何回かおしてみよう。何が出るかな？

<led-rps></led-rps>

<details>
<summary>「でたらめな数」って？</summary>

さいころをふると、1 から 6 のどれが出るか分からないよね。
コンピューターも同じように、どれが出るか分からない数を作れるんだ。これを「乱数（らんすう）」というよ。
今回は 1 から 3 の乱数を作って、1 ならグー、2 ならパー、3 ならチョキを出すよ。

</details>

#### 前半：でたらめな数を作る

- [ ] 「変数」で「変数を追加する...」をおし、名前を「て」にした
- [ ] 「入力」から「ゆさぶられたとき」を出して、あいているところにおいた
- [ ] 「変数」から「変数 て を 0 にする」を出して、「ゆさぶられたとき」の中に入れた
- [ ] 「計算」から「0 から 10 までの乱数」を出して、「0 にする」の 0 のところに入れた
- [ ] 「0 から 10」を「1 から 3」にかえた

#### 後半：数によって出す絵をかえる

- [ ] 「論理」から「もし ～ なら ～ でなければ」を出して、「変数 て を…」の下に入れた
- [ ] 「でなければ」の下の ⊕ をおして、「でなければもし」をふやした
- [ ] 「論理」から「0 = 0」を出して、「もし」と「でなければもし」の横にそれぞれ入れた
- [ ] 「変数」の中のまるい「て」を、2つの「0 = 0」の左の 0 に入れた
- [ ] 右の 0 を、上は 1、下は 2 にかえた
- [ ] 「基本」から「アイコンを表示」を3つ出して、それぞれの下に入れた
- [ ] ▼ で、上から「小さいしかく」（グー）、「しかく」（パー）、「はさみ」（チョキ）をえらんだ（一覧の下のほうにあるので、スクロールしてね）
- [ ] シミュレーターの「SHAKE」をおして、グー・チョキ・パーのどれかが出た

<details>
<summary>SHAKE を何回おしても、同じ絵のままのときは？</summary>

課題4の歩数計と同じで、シミュレーターでは SHAKE をつづけておしても、2回目からは反応しないことがあるよ。
マウスをシミュレーターの micro:bit の上で少し動かしてから、もう一度 SHAKE をおしてみよう。
それでも同じ絵が出ることはあるよ。じゃんけんだから、同じ手がつづくこともあるんだ。

</details>

<details>
<summary>チョキが出ないときは？</summary>

いちばん下の「でなければ」の下に、はさみの「アイコンを表示」が入っているか見てみよう。
それから、乱数が「1 から 3」になっているかも見てね。「1 から 2」だと 3 が出ないよ。

</details>

<details>
<summary>何も出ないときは？</summary>

「もし ～ なら」が、「ゆさぶられたとき」の中の、「変数 て を…」の下に入っているか見てみよう。
外に出ていると、ゆさぶっても動かないよ。

</details>

## おやこ

乱数と、3つに分かれる「もし～なら」を使う、6つの課題のまとめです。
手順が多いので、前半と後半で休けいをはさんでもかまいません。

### すすめかた（45分）

- [ ] 「できあがりのイメージ」で、何回かじゃんけんをして遊んだ
- [ ] 子どもが「こども」タブの前半を進めた
- [ ] 休けいのあと、後半を進めた
- [ ] 実機で、家族とじゃんけん勝負をした

### 声かけのヒント

> さいころとじゃんけんマシンは、どこがにている？
>
> 「1 から 3」を「1 から 4」にしたら、どうなると思う？
>
> ずるいじゃんけんマシン（グーが出やすい）を作るには、どうしたらいいかな？

2つ目の問いは、試すと「4 のときは『でなければ』に入るので、チョキが出やすくなる」ことがわかります。
3つ目は少し難しいですが、「乱数の範囲を広げて、グーになる数をふやす」などのアイデアが出れば大成功です。

## おとな

保護者の方がご自身で学ぶ場合や、お子さんに教える前の準備に使うページです。

### この課題で学ぶこと

- **乱数**：「1 から 3 までの乱数」は、実行するたびに 1・2・3 のどれかを返します。
- **変数への代入**：乱数の結果を変数「て」に入れておき、あとの判断で使います。
- **多分岐**：「もし～なら／でなければもし～なら／でなければ」で、3つ以上の場合に分けて処理します。

### ちょっとした補足

この教材では、グー・パー・チョキの絵に、MakeCode の「アイコンを表示」にある「小さいしかく」「しかく」「はさみ」を使っています（一覧の下のほうにあります）。
microbit.org の元の課題では、「LED画面に表示」で手の形を描いています。

「でなければ」に入るのは「て が 1 でも 2 でもないとき」です。乱数の範囲が 1〜3 なら、これは 3 のときだけになります。
もし範囲を 1〜4 に広げると、3 と 4 の両方がチョキになり、チョキが出やすくなります。おやこタブの問いは、このしくみを体験するためのものです。
