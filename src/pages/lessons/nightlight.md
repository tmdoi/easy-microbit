## こども

暗くなると自動でつくライトを作ろう。
micro:bit の LED は、光るだけでなく、まわりの明るさを感じるセンサーにもなるんだ。

### できあがりのイメージ

下のスライダーを 🌙 のほうへ動かして、まわりを暗くしてみよう。どこでライトがつくかな？

<led-light threshold="100"></led-light>

<details>
<summary>「明るさ」って、どんな数？</summary>

micro:bit は、まわりの明るさを 0 から 255 までの数で教えてくれるよ。
0 はまっくら、255 はとても明るいという意味。
今回は「明るさが 100 より小さかったら、暗いからライトをつける」というプログラムを作るよ。

</details>

- [ ] 「論理」から「もし ～ なら ～ でなければ」を出して、「ずっと」の中に入れた
- [ ] 「論理」から「0 < 0」を出して、「もし」の横の「真」のところに入れた
- [ ] 「入力」から「明るさ」を出して、「0 < 0」の左の 0 のところに入れた
- [ ] 右の 0 を 100 にかえた
- [ ] 「基本」から「アイコンを表示」を出して、「なら」の下に入れた
- [ ] 「基本」から「表示を消す」を出して、「でなければ」の下に入れた
- [ ] シミュレーターの明るさを下げて、ハートがついた

<details>
<summary>シミュレーターで、どうやって暗くするの？</summary>

「明るさ」を使うと、シミュレーターの micro:bit の左上に、明るさの数が書かれた丸が出てくるよ（はじめは 128）。
その丸の上でマウスを上へドラッグすると暗く（数が小さく）、下へドラッグすると明るく（数が大きく）なるよ。
丸の横の数を見ながら動かしてみよう。100 より小さくなると、ハートがつくよ。

</details>

<details>
<summary>暗くしても、ハートがつかないときは？</summary>

「0 < 0」の左に「明るさ」、右に「100」が入っているか見てみよう。
左右が反対だと、「100 より明るいとき」につくライトになってしまうよ。
くらべる記号が「<」（小さい）になっているかも見てね。

</details>

<details>
<summary>明るくしても、ハートが消えないときは？</summary>

「表示を消す」が、「でなければ」の下に入っているか見てみよう。
これがないと、一度ついたハートが消えないままになるよ。

</details>

## おやこ

センサーで明るさをはかって、条件によって動きを変える「もし～なら」を使う課題です。
これまでで一番考えることが多い課題なので、ゆっくり進めてください。

### すすめかた（45分）

- [ ] 「できあがりのイメージ」で、ライトがつく明るさをいっしょに探した
- [ ] 子どもが「こども」タブの手順を、声に出して読みながら進めた
- [ ] シミュレーターで明るさを変えて、ハートがつくのを確かめた
- [ ] 実機を部屋の暗い場所に持っていって試した

### 声かけのヒント

> 「もし」と「でなければ」は、ふだんの生活だとどんなときに使う？
>
> 家の中で、暗くなると自動でつくものはあるかな？
>
> 「100」を「200」にしたら、ライトはつきやすくなる？つきにくくなる？

「もし雨なら かさを持っていく、でなければ持っていかない」のように、日常の判断と結びつけると「条件分岐」がぐっと分かりやすくなります。
3つ目の問いは、チャレンジの micro:bit で予想を確かめられます。

<details>
<summary>LED がセンサーになるしくみ</summary>

micro:bit には明るさ専用のセンサーはなく、LED を使って明るさを測っています。
「光を出す部品が、光を感じることもできる」というのは、大人にとっても面白い発見です。

</details>

## おとな

保護者の方がご自身で学ぶ場合や、お子さんに教える前の準備に使うページです。

### この課題で学ぶこと

- **条件分岐**：「もし～なら～でなければ」で、条件によって実行する処理を選びます。
- **比較**：「明るさ < 100」のように、2つの値をくらべて、正しい（真）か正しくない（偽）かを判断します。
- **センサーとくり返し**：「ずっと」の中で明るさを何度も測ることで、明るさが変わったときにすぐ反応します。

### ちょっとした補足

micro:bit の「明るさ」は、0（暗い）から 255（明るい）の値を返します。
実際の部屋の明るさや光の当たり方で値は大きく変わるので、「100」は目安です。
お子さんと一緒に「数を表示」で明るさの値を表示させて、部屋の明るさを測ってみると、ちょうどよい数を決められます。

この教材の「できあがりのイメージ」では、課題を作りやすくするため、ライトに「アイコンを表示」のハートを使っています。
microbit.org の元の課題では、「LED画面に表示」で全部の LED をつけています。
