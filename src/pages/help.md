# こまったとき

うまくいかないときは、ここを見てみよう。

## パソコンにつないでも、何も起きない

- USB ケーブルが、じゅう電だけのケーブルかもしれません。別のケーブルでためしてみよう。
- micro:bit のうらの黄色いランプがつくか見てみよう。つかないときは、ケーブルをさしなおそう。

## シミュレーターでは動くのに、micro:bit では動かない

- 「ダウンロード」をした後、micro:bit にちゃんと送れたか、たしかめよう。
- 電池ボックスでつかっているときは、電池が切れていないか見てみよう。

## 名前が表示されない

- micro:bit はひらがなや漢字を表示できません。ローマ字で書こう。
- ブロックが「ずっと」の中にカチッと入っているか見てみよう。

## ここにない こまりごと

[GitHub の Issue](https://github.com/tmdoi/easy-microbit/issues) で教えてください。このページに追加します。
